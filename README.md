# Ever After Studio — Wedding PDF storefront preview

Open index.html or run `python -m http.server 8000` in this folder.

Includes ten product cards, detail dialogs, actual interior page previews, original OpenAI-generated visuals and all ten user-provided $8.99 Jim checkout links.

**This is a static preview, not a live fulfillment system.** Jim does not provide payment webhooks or API, so orders cannot be automatically verified. Seller must verify in Jim and approve delivery manually. Full paid PDFs are deliberately not included in this public package.

Before public launch: confirm final brand, add support email, refund policy, privacy policy, terms, a secure order-intake workflow, private file storage, authenticated approval dashboard and transactional email delivery. Avoid collecting personal details in static HTML without a secure backend. Do not use live checkout links for test purchases unless intending to pay.
